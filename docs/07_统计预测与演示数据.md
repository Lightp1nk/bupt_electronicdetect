# 统计预测与演示数据

## 目的

基于已保存快照计算每日耗电、近 3/7 日平均和预计可用天数，并说明只读演示数据的隔离方式。

## 统计计算

`StatisticsService` 从 `ElectricityDataProvider` 读取 `get_history()` 与 `get_latest()`。真实模式使用 `RealElectricityDataProvider` 查询 `electricity_records`；服务本身不写入统计结果。

计算规则：

1. 每个 `source_date` 保留该日最后一个有效累计用电读数；
2. 仅对相邻日计算累计用电差；
3. 忽略缺少数据、跨日期空档和用电累计倒退的记录；
4. 有至少 3 个有效日数据时给出近 3 日平均与 preliminary 预测；至少 7 个有效日时给出近 7 日平均与 stable 预测；
5. 预计可用天数为 `remaining_kwh / selected_average`，没有有效平均时为 `null`。

## 演示数据模式

设置 `DEMO_MODE_ENABLED=true` 后，已登录用户访问 `?demo=1` 可读取 `app/demo_data/demo_electricity_history.json`。数据集包含连续 90 天以上的正常波动、异常峰值和余额下降，前端会清楚标记“演示数据”。

Demo Provider 仅有 `get_latest()` 与 `get_history()` 两个只读方法，不能访问 Runtime Client、SQLite 写入、Collection、Scheduler、Alert、Notification 或 AstrBot。演示预警仅是前端展示，不创建 `AlertEvent` 或 `NotificationDelivery`。

## 注意事项

- 正常生产默认 `DEMO_MODE_ENABLED=false`。
- 演示入口不绕过 App Session 登录。
- Heatmap 和趋势图均使用 StatisticsService 与后端返回数据，不使用旧前端 mock 数据源。
