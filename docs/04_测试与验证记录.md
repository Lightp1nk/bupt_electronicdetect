## 4 阶段 3：进程内 Session 管理

工具：`scripts/session_probe.py`，需要启动 FastAPI 后执行。实际运行已成功验证：登录 → status=true → 两次 `buildings` 业务请求 → status=true → logout → status=false → 登出后受保护路由返回 `AUTH_REQUIRED`。

脱敏结果：

```text
login: OK
status after login: OK
business request 1: OK
Business request 1: reused active server session.
business request 2: OK
Business request 2: reused active server session.
status after repeated business requests: OK
logout: OK
status after logout: OK
SESSION PROBE SUCCESS
```

该验证确认连续请求没有再次询问密码。当前最小 HTTP 业务路由只验证楼栋列表；完整楼栋→宿舍→电费的交互式验证仍由 `scripts/electricity_probe.py` 完成。
