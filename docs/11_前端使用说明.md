# 前端使用说明

## 目的

说明 Vue 前端已实现的登录、仪表板、宿舍设置、预警设置和 AstrBot QQ 绑定交互。

## 页面与行为

- 登录页：提交北邮账号和密码；前端不持久化密码或上游 Cookie。
- 仪表板：显示最近快照、预警、年度 Heatmap、统计摘要、累计用电与余额趋势。
- 设置页：选择宿舍后同时写入浏览器 localStorage（展示兼容）和后端 collection settings（自动采集来源）。后端保存失败会显示错误，不会误报自动采集已配置。
- 预警设置：读取和保存当前用户的 alert settings。
- 通知与 QQ 绑定：先生成绑定码并在 QQ 私聊绑定；网页仅启停已验证 QQ 的通知，不手填 QQ ID。
- AstrBot 接入页：展示通知状态与绑定步骤。

## 首次加载与刷新

登录后仪表板优先读取已保存的 latest/history/analysis；用户点击“刷新”才执行实时上游查询。这样避免每次打开页面都请求北邮。

## 演示模式

在服务端启用 Demo Mode 后，已登录访问 `?demo=1`。前端显著显示“演示数据”，隐藏设置与 AstrBot 写操作，并读取后端演示 API 数据。演示预警只用于视觉展示。

## 降级处理

若生产环境后端配置了 `DEMO_MODE_ENABLED=false`，API 将拒绝该请求并返回 403 错误。前端检测到此错误后，必须抛出全局提示（如“演示模式已在服务器端禁用”），自动清除 URL 中的 `?demo=1` 参数并刷新页面，退回真实数据模式。避免在请求被拒时仍隐藏正常的系统设置入口导致死锁。

## 安全注意事项

- App Session 由 HttpOnly Cookie 维护，前端代码不读取原始 token。
- `user_id`、Internal Token、UMO、上游 Cookie 均不出现在前端 API 参数或页面中。
