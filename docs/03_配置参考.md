# 配置参考

## 目的

本文列出源码实际读取的环境变量。示例均为占位值，不可复制为生产秘密。环境变量应由受权限保护的环境文件、systemd `EnvironmentFile` 或容器环境注入，不应写入 Git、数据库或前端。

## FastAPI 与数据库

| 变量 | 必须 | 默认值 | 作用 | 示例占位 |
| --- | --- | --- | --- | --- |
| `APP_DATABASE_URL` | 否 | `sqlite+aiosqlite:///./data/electricity.db` | SQLite Async URL；生产应指向持久化路径 | `sqlite+aiosqlite:////srv/app/data/electricity.db` |
| `APP_UPSTREAM_SESSION_KEY` | 是（登录/恢复上游 Session） | 无 | Fernet Key，加密 `upstream_sessions` Cookie payload | `<fernet-key>` |
| `APP_SESSION_TTL_HOURS` | 否 | `336` | 浏览器 App Session 有效期，小时 | `336` |
| `APP_SESSION_LAST_SEEN_INTERVAL_SECONDS` | 否 | `300` | App Session `last_seen_at` 的最小更新间隔 | `300` |
| `APP_SESSION_COOKIE_SECURE` | 生产建议是 | `false` | Cookie 是否仅经 HTTPS 发送 | `true` |
| `APP_DISABLE_UPSTREAM_QUERIES` | 否 | `false` | 禁止 `POST /electricity/query` 的测试隔离开关 | `true` |
| `DEMO_MODE_ENABLED` | 否 | `false` | 启用受登录保护的 `?demo=1` 后端只读演示数据 | `true` |

`APP_UPSTREAM_SESSION_KEY` 必须是有效 Fernet Key。服务不会生成临时 Key，也不会降级为明文保存。

## 自动采集

| 变量 | 必须 | 默认值 | 作用 | 示例占位 |
| --- | --- | --- | --- | --- |
| `COLLECTION_ENABLED` | 否 | `true` | 是否注册每日采集 Job | `true` |
| `COLLECTION_HOUR` | 否 | `4` | `Asia/Shanghai` 时区的小时 | `4` |
| `COLLECTION_MINUTE` | 否 | `0` | `Asia/Shanghai` 时区的分钟 | `0` |
| `COLLECTION_MAX_CONCURRENCY` | 否 | `3` | 多用户采集的最大并发任务数 | `3` |

兼容旧配置名：`ELECTRICITY_COLLECTION_ENABLED`、`ELECTRICITY_COLLECTION_HOUR`、`ELECTRICITY_COLLECTION_MINUTE`。新部署优先使用 `COLLECTION_*`。

## AstrBot Bridge 通知

| 变量 | 必须 | 默认值 | 作用 | 示例占位 |
| --- | --- | --- | --- | --- |
| `ASTRBOT_BRIDGE_ENDPOINT` | 通知功能需要 | 无 | AstrBot Bridge 根地址；后端会请求其 `/api/send` | `https://astrbot.example.internal/...` |
| `ASTRBOT_BRIDGE_TOKEN` | 依 Bridge 配置 | 无 | FastAPI 到 Bridge 的 Bearer Token | `<bridge-token>` |
| `ASTRBOT_INTERNAL_TOKEN` | QQ 绑定和查询需要 | 无 | AstrBot 到 FastAPI Internal API 的 Bearer Token | `<internal-token>` |

Bridge Endpoint 未配置时，通知投递会记录失败，但不得影响电费查询、快照保存或 Alert 状态。

## AstrBot 插件环境

下列变量由 AstrBot 容器注入插件，而非由 FastAPI 读取。

| 变量 | 必须 | 作用 | 示例占位 |
| --- | --- | --- | --- |
| `BUPTELEC_APP_ENDPOINT` | 是 | FastAPI 根地址，用于 `/api/internal/chat/*` | `https://electricity.example.com` |
| `BUPTELEC_BRIDGE_TOKEN` | Bridge 受保护时需要 | 应与 FastAPI `ASTRBOT_BRIDGE_TOKEN` 相同 | `<bridge-token>` |
| `BUPTELEC_INTERNAL_TOKEN` | 是 | 应与 FastAPI `ASTRBOT_INTERNAL_TOKEN` 相同 | `<internal-token>` |

`BUPTELEC_INTERNAL_TOKEN` 与 `ASTRBOT_INTERNAL_TOKEN` 必须完全一致；Bridge Token 与 Internal Token 的职责不同，建议使用不同随机值。

## 配置检查

- 不打印变量值，只确认 `present` / `missing`。
- 修改 systemd 环境文件后需要重启 FastAPI；修改 AstrBot 容器环境后需要重启容器。
- 生产环境正常运行时建议 `DEMO_MODE_ENABLED=false`、`APP_DISABLE_UPSTREAM_QUERIES=false`。
