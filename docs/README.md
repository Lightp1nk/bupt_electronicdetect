# 《宿舍用电监测与智能提醒系统》文档目录

本目录保存课程项目的第一版软件工程文档。文档以当前仓库代码、自动化测试和已经记录的人工探针结果为准；计划项不会表述为已交付功能。

当前开发阶段：已完成统一认证、单宿舍电费数据采集客户端、进程内 Session 管理，以及 SQLite 历史快照链路的自动化验证。真实上游的数据库写入与重复快照验证待运行 `database_probe.py` 后归档；统计预测和前端尚未进入实现阶段。

状态标记含义：**已实现并验证** 表示已有自动化测试或实际人工探针记录；**已实现但尚未真实验证** 表示代码存在但尚未完成对应真实上游场景的验证；**规划中，尚未实现** 表示不在当前代码范围内。当前未发现需要单独列为“已实现但尚未真实验证”的主要功能；后续新增功能将按此标记记录。
